# Particles

Interactive 2D/3D particle sandbox. Heat, freeze, and melt matter with lattice bonds or an SPH fluid solver.

[Start](https://denv3rr.github.io/particles/)

## Features
- Phase-aware materials: iron, gold, water, oxygen, nitrogen, and argon.
- Lattice solver with neighbor springs, strain-based bond breaking, and local melting.
- SPH fluid mode with viscosity, stiffness, surface tension, and velocity smoothing.
- Ambient temperature plus a heat brush (drag in 2D, Shift-drag in 3D).
- 3D orbit, pan, zoom, and optional bounds.
- Flow tracers, pause, and a compact control panel.

## Controls
- **2D:** drag to inject heat. Space pauses.
- **3D:** drag to orbit, scroll to zoom, right-drag to pan, Shift-drag to heat.
- Arrow keys rotate, WASD pan, +/- zoom.
- Room / Melt / Boil chips jump to useful temperatures for the current material.
